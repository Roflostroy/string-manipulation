# String Manipulator Bash Script

**Универсальный Bash-скрипт для быстрой работы со строками.** Позволяет искать подстроки, делать срезы, заменять текст, а также удалять и вставлять символы в любой части строки. Скрипт поддерживает два режима работы: интерактивное меню и передачу параметров через аргументы командной строки (CLI).

---

## 🚀 Возможности

Скрипт разбит на 5 основных модулей:

* **Поиск (`search`)** — проверяет наличие подстроки и выводит индекс её начала (с 0).
* **Срез (`slice`)** — извлекает часть строки по указанному индексу и длине.
* **Замена (`replace`)** — заменяет все вхождения одной подстроки на другую.
* **Удаление (`delete`)** — удаляет символы из начала, конца, середины или по указанному диапазону индексов.
* **Добавление (`insert`)** — вставляет текст в начало, конец или на определенную позицию.

---

## 🛠 Способы запуска

Перед первым запуском не забудьте сделать скрипт исполняемым:
```bash
chmod +x str
```

### 1. Интерактивный режим
Если запустить скрипт без аргументов, он сам спросит строку и предложит меню выбора действий:
```bash
./str
```

### 2. Режим аргументов командной строки (CLI)
Вы можете передать все параметры сразу при вызове по шаблону: `[исходная_строка] [команда] [параметры...]`.

#### Примеры быстрых команд:

* **Поиск:**
  ```bash
  ./str "Привет, мир!" search "мир"
  # Выведет: Подстрока существует / Позиция начала (с 0): 8
  ```
* **Срез:**
  ```bash
  ./str "Привет, мир!" slice 0 6
  # Выведет: Привет
  ```
* **Замена:**
  ```bash
  ./str "Кот на крыше" replace "Кот" "Пес"
  # Выведет: Пес на крыше
  ```
* **Удаление из середины:**
  ```bash
  ./str "0123456789" delete mid 3 4
  # Из строки "0123456789" удалит 4 символа начиная с 3-го индекса. Выведет: 012789
  ```
* **Удаление по диапазону (включительно):**
  ```bash
  ./str "0123456789" delete range 3 6
  # Удалит символы с 3-го по 6-й индексы включительно (вырежет "3456"). Выведет: 012789
  ```
* **Вставка в позицию:**
  ```bash
  ./str "Летят птицы" insert pos 6 " быстрые"
  # Выведет: Летят быстрые птицы
  ```

## 📝 Справка по аргументам CLI

| Команда (`$c`) | Действие (`$d`) | Полный синтаксис вызова |
| :--- | :--- | :--- |
| **`search`** | — | `./str "[строка]" search "[что_искать]"` |
| **`slice`** | — | `./str "[строка]" slice [старт] [длина]` |
| **`replace`** | — | `./str "[строка]" replace "[что_менять]" "[на_что]"` |
| **`delete`** | `start` / `end` | `./str "[строка]" delete [start\|end] [кол-во_символов]` |
| | `mid` | `./str "[строка]" delete mid [старт] [длина]` |
| | `range` | `./str "[строка]" delete range [индекс_от] [индекс_до]` |
| **`insert`** | `start` / `end` | `./str "[строка]" insert [start\|end] "[что_вставить]"` |
| | `pos` | `./str "[строка]" insert pos [индекс] "[что_вставить]"` |

## 💻 Требования

* Локальный интерпретатор **Bash** (протестировано на Bash 4.0 и выше).
* Стандартные утилиты окружения Linux/macOS (внешние зависимости вроде `sed`, `awk` или `grep` **не используются**, всё написано на чистом Pure Bash).
